# پنجره روشنایی | Panjereh Roshanayi

پروژه دانشگاهی طراحی و پیاده‌سازی وب‌سایت معرفی خدمات کلینیک پنجره روشنایی.

## اجرای نسخه نمایشی

فایل `index.html` را در مرورگر باز کنید یا با افزونه Live Server در VS Code اجرا کنید. طراحی صفحات، تصاویر و تعاملات سمت کاربر قابل نمایش‌اند.

## ساختار پروژه

- `index.html` — صفحه اصلی
- `css/style.css` — استایل‌ها
- `js/script.js` — تعاملات صفحه و اعتبارسنجی فرم
- `images/` — تصاویر و آیکون‌های سایت
- `_worker.js` — نمونه بک‌اند فرم تماس برای Cloudflare Pages و Resend

## وضعیت دامنه و فرم تماس

دامنه `panjerehroshanayi.ir` در انتظار تأیید ایرنیک است. فعال‌نبودن دامنه مانع بررسی فایل‌های پروژه نیست.

فرم تماس در اجرای محلی ایمیل واقعی ارسال نمی‌کند. ارسال ایمیل به پیکربندی امن متغیرهای محیطی در Cloudflare و سرویس Resend وابسته است. هیچ کلید API یا اطلاعات محرمانه‌ای در این مخزن قرار ندهید.

این بسته نسخه Cloudflare است؛ پیکربندی PHP هاست cPanel در آن قرار ندارد.

تصاویر فضای کلینیک نمایشی‌اند و عکس واقعی محل نیستند.
